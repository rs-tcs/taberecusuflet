TeameXpert Sports Events >> Trophy >> 2013 >> RiderS 2013

Trofeul TeamXpert Sports Events reuneste competitiile organizate de TeamXpert Sports Events si Asociatia Tabere cu Suflet in 2013, la 4 discipline sportive. La aceste competitii au luat parte peste 1100 de rideri.
Discipline sportive: S&S = Schi sau Snowboard, F = Freeriding, TR = Trail running, MTB = Mountainbike, MTBU = Mountainbike Uphill.
Categorii: A = Adulti, S = Seniori, P = Pitici, C = Copii, S = Spiridusi, U = Uriasi
